# 工程5: 人間による仕上げ

## 考え方

**AIを使うと質が落ちる、ということはない。**

落ちるのは、AIの出力をそのまま出したときである。
**最後の5%を人間が担うことで独自性が生まれる。**

95%はAIで到達できる。だが95%の教材は、同じくAIを使う他者の95%と区別がつかない。
差がつくのは残りの5%だけであり、そこは代替できない。

## 人間がやるべき3領域

### 1. 顧客サポート

受講生の個別の状況に答える部分。

ここは効率化の対象ではない。**次の講座の材料を採取する工程**である。
サポートで受けた質問は、そのまま [inputs/qa-log.md](inputs/qa-log.md) に蓄積する。
それが次の工程1・2の入力になる。

サポートを外注・自動化すると、この循環が切れる。
講座が更新されなくなる原因は、たいていここにある。

- 受けた質問は必ずログに残す（要約せず、原文のまま）
- 同じ質問が3回来たら、それは教材の欠陥である。教材を直す

### 2. フロント活動

セミナー、説明会、対面の場。

声・間・熱量は文章に落ちない。
受講前の人が「この人から学ぶか」を判断する材料は、ここにしかない。

### 3. 意思決定

何を作るか、何を作らないか、誰に売らないか。

AIは選択肢を出せるが、**捨てる判断はできない**。
工程1で円が2つしか重ならない案を捨てる、工程4で基準を満たさない特典を捨てる。
この「捨てる」がすべて人間の仕事である。

判断は必ず理由とともに記録する（各工程の判断ログ・却下欄）。
記録がないと、後で同じ検討を繰り返す。

## 境界線

| 領域 | 担当 | 理由 |
| --- | --- | --- |
| 構成の下書き | AI | 量とパターンの処理 |
| 台本の初稿 | AI | 文体は過去原稿から学習させる |
| つまずき順の整理 | AI | ログの分析 |
| 体験・失敗談 | 人間 | 持っている人しか書けない |
| 音読による違和感の修正 | 人間 | 話せるかは身体でしか判定できない |
| 捨てる判断 | 人間 | 基準を適用する責任 |
| 顧客サポート | 人間 | 次の材料の採取を兼ねる |
| フロント活動 | 人間 | 判断材料そのものが人間 |

## 出す前の最終確認

- [ ] AIが推測で埋めた事実誤認が残っていないか（特に数値・制度・法令）
- [ ] 自分の体験が3〜4割入っているか（工程3-⑤）
- [ ] 全章を音読したか（工程3-④）
- [ ] 学習ゴールと所要時間が受講生から見えるか（工程2）
- [ ] 特典が6基準を満たしているか（工程4）
- [ ] サポートで得た質問をログに戻す仕組みがあるか
