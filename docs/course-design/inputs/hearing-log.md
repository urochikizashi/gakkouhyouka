# 顧客ヒアリング記録

工程1（[コンセプト設計](../01-concept.md)）の入力。**10件を目標**に埋める。

## 書き方

**要約しないこと。話し言葉のまま貼ること。**

要約した瞬間に、翻訳すべき「生の言葉」が失われる。
講座名やキャッチコピーは、ここに書かれた言葉から直接取り出す。だから加工してはいけない。

| ✗ 書かないでほしい形 | ○ 書いてほしい形 |
| --- | --- |
| 業務効率化に課題を感じている | 「毎年これ、土日が丸ごと消えるんですよ」 |
| 分析手法に不安がある | 「集計はできるけど、で、これ何が言えるの?って言われると詰まる」 |
| 情報発信に苦手意識がある | 「保護者に配る一枚を作るのに、毎回3日悩んでます」 |

拾うべきもの:

- 口ぐせ、言い回しの癖、感情が出た言葉（「しんどい」「意味あるのかな」「怖い」）
- 諦めの言葉、愚痴、言いかけてやめたこと
- **困っている状態の描写**（本人が語る解決策より優先）

**新規に集める場合**: 「何に困っていますか」ではなく
「直近でいちばん時間を取られた作業は何でしたか」「そのとき何を思いましたか」と聞く。
前者は整った答えが返り、後者は生の言葉が返る。
