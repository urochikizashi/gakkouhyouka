# Q&Aログ

工程2（[カリキュラム設計](../02-curriculum.md)）と工程3（[台本の量産](../03-script.md)）の入力。

## 書き方

これは**つまずきの実測データ**である。自分の記憶ではなく、実際に受けた質問を記録する。
作り手は自分がつまずいた記憶を失っているため、記憶に頼ると必ず順序を間違える。

- **質問は原文のまま**。整えると、どこで詰まったかの情報が消える
- **発生タイミング**が最重要項目。件数より優先する
- 答えられなかった質問、うまく答えられなかった質問も残す（教材の欠陥箇所を示している）

`段階` の書き方: 「学習のどの時点で出たか」を書く。
例: 「着手前」「最初の作業中」「一通りやった後」「実務に適用しようとしたとき」

工程5のとおり、サポートで受けた質問はここに戻し続ける。これが次の講座改訂の材料になる。
