# 競合調査

工程1（[コンセプト設計](01-concept.md)）の「競合の隙間」を埋めるための調査。

- 調査日: 2026-07-30
- 調査方法: Web検索（約10分）。**網羅的調査ではない**
- 制約: `mext.go.jp` と `code.or.jp` は直接取得できず（403）、検索結果のスニペット経由で確認した。
  一次資料の原文確認は未了。数値と日付は下記「要検証」を参照

## 結論から

**当初の仮説は片方が外れた。**

| 当初の仮説 | 検証結果 |
| --- | --- |
| 既存研修は「AIの機能紹介」から入り、苦痛から出発していない | **部分的に当たり**。ただし不安から入る研修は既に存在する |
| 既存研修は現場の制約（個人情報・ルール）を明言しない | **外れ**。制約明言は業界標準になっている |

したがって「制約を先に明言すること」は差別化にならない。**それは前提条件である。**

一方で、調査中に**別の隙間**が浮上した。隙間は入口（不安・制約）ではなく**出口（研修後の定着）**にある。詳細は後述。

## 競合の層構造

### 第1層: 文部科学省（無料・公式）— 最大の競合

| 提供物 | 内容 |
| --- | --- |
| 生成AIに関する教員向け研修動画シリーズ | 東北大・東京学芸大・信州大・東大の教授が講師。ガイドライン理解、生成AIの性質と限界 |
| 生成AIの利用に関するオンライン研修会 | 基礎と活用可能性、教育活動・教務で使えるプロンプト紹介、情報活用能力の育成 |
| 初等中等教育段階における生成AIの利活用に関するガイドライン Ver.2.0 | 2024年12月26日公表。個人情報・著作権の留意点を**主体別・場面別に明示** |
| 校務での生成AI活用 好事例集（教育委員会向け手引） | 2026年6月発表。2026年度中に取りまとめ予定 |
| セキュアな環境における生成AIの校務利用 実証研究事業 | 令和7年度実施。成果報告会 2026年3月17日 |

**無料 + 公式 + ガイドライン準拠**。この層と正面から競合するのは不可能である。
ここが埋めない部分を埋めるしかない。

さらに、参加者が**すでにこの動画を見ている可能性**を前提に設計する必要がある。
同じ内容を有料または貴重な研修時間で繰り返せば、それ自体が「時間を取られた」体験になる。

### 第2層: NPO（無料）

**みんなのコード** — 中高教員向けオンライン研修「はじめての生成AI」（無料開催）

注目すべきは設計思想である。記事タイトルが
**「不安が『使ってみたい！』に変わる教員向け生成AI研修」**。

- 生成AIの**仕組みの理解**を経由して不安を解く（検索ではなく生成である／確率で言葉をつないでいる／意味そのものは理解していない）
- メリットとデメリットの双方を考える場として設計
- 「AIにコードを書かせたら学びにならないのでは」といった懸念に正面から対応
- 研修後に校務効率化・ルーブリック・学習計画などの活用アイデアが参加者から出ている

**これは工程0で立てた「不安・苦痛から入る」設計を、すでに実装している。**
「誰もやっていない」という前提は成立しない。

### 第4層: 自治体・教育委員会の内部研修

**令和6年度時点で、大きな自治体ほど研修を実施している。
小規模自治体および生成AIを活用していない自治体は、研修を実施していない傾向。**

→ これは明確なターゲット隙間である（後述）。

### 第5層: 個人発信

元教員・現職教員によるnote等での実践発信（例: 「ChatGPTで校務爆速術」）。
無料で具体的、かつ現場の言葉で書かれている。**信頼性の面で強い競合**である。

| 形式 | 相場 |

| eラーニング型 | 1人あたり 5〜10万円 |

学校向けは無料の公的・NPO提供が充実しているため、この相場より下方圧力が強いと想定される（未検証）。

## 本当の隙間（新しい仮説）

調査中に見つかった「生成AI研修が現場で使われない理由」の分析が、そのまま隙間を示していた。
これらは企業研修の文脈だが、指摘の構造は学校にもそのまま当てはまる。

引用された指摘:

- 研修後に**「自分の業務でどう使うか」が設計されていない**
- 「生成AIの歴史」「AIの種類」といった知識は、**明日の業務を変えない**
- 汎用的な演習をしても、通常業務に戻ると「自分の仕事ではどこで使えるのか」の壁にぶつかる
- 使わないのは意識の問題ではなく、**「使いたくても使えない・使っても評価されない」構造的問題**が先にある

### 隙間A: 出口（定着）の設計

第1〜3層はいずれも**研修の中**を設計している。研修後に定着させる設計は手薄である。

これは工程0-3「参加者が明日やる業務で実演する」と一致する。**ここを強化する。**

差別化になるのは制約の明言ではなく、**参加者自身の業務が、その場で1つ終わること**である。

### 隙間B: 学校ごとの「できることの差」

生成AIで何ができるかは、学校の環境で全く変わる。

- **セキュア環境あり** → 実証研究では通知表の所見作成まで可能（指導要録を登録した状態でのサポート）
- **セキュア環境なし** → 個人情報を入力できないため、扱える業務が大幅に限られる

そして**次世代校務DXの導入済み自治体は6.1%**（2026年6月30日 第10回デジタル学習基盤特別委員会報告）。
つまり**大多数の学校はセキュア環境がない側**にいる。

環境の違いで内容を分けている研修は、調査範囲では見当たらなかった。
一律の内容を出すと、参加者の一部に必ず「うちでは使えない」が発生する。

### 隙間C: 研修が届いていない層

小規模自治体・生成AI未活用自治体は研修を実施していない傾向がある。
**研修が最も届いていない層が、最も苦痛を抱えている可能性**がある。

ただしこの層は予算も小さい。有料前提だと成立しない可能性が高い。

## ターゲット「広く学校現場の人」への影響

**指摘**: 今回の調査は、対象を広く取ることの困難を実データで裏付けた。

- セキュア環境の有無で、できる業務が根本的に違う（導入済み6.1%）
- 自治体規模で、研修の実施状況も生成AIへの慣れも違う
- 立場（担任／管理職／事務職員）で苦痛が違う

対象を広く取ると、**参加者の一部に必ず「うちでは使えない」「もう知っている」が発生する**。
これは前回「響かなかった」ことの一因である可能性が高い（工程0の点検表「学校ごとの差」「立場の差」）。

### 「広く」で行く場合の設計（対象を絞らない前提での対処）

対象を広く取る判断であれば、内容側で差を吸収する。

1. **冒頭で参加者を分岐させる** — セキュア環境の有無、自治体の許可状況を挙手や簡単な確認で把握し、以降の実演をどちらかに寄せる
2. **共通部分を「個人情報を入力しない前提で完結する業務」に絞る** — この範囲なら全員に当てはまり、「うちでは使えない」が発生しない
3. **セキュア環境がある学校向けの内容は分岐させて後半に置く** — 該当者だけが持ち帰る
4. **文科省動画で足りる内容を講座から外す** — 生成AIの仕組み・歴史・一般的な注意点は既に無料で存在する。ここに時間を使わない

4番が最も効く。**無料で手に入る内容を有料または貴重な研修時間で出さない**ことが、
そのまま参加者の時間を守ることになる。
