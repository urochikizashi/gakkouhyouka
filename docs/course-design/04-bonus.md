# 工程4: 特典の設計

## 考え方

**量ではなく質。**

特典が多いことは価値ではない。特典が多い商品は、むしろ
「メイン商品だけでは足りないのだろう」という疑いを生む。

特典の役割はただ一つ、**メイン商品の弱点を補完すること**である。

## 6つの基準

**6つすべてを満たさない特典は採用しない。** 1つでも欠けたら捨てるか作り直す。

### 1. メイン商品の弱点を補完する

メイン商品で扱いきれなかった部分、受講生が実行段階で詰まる部分を埋める。
メイン商品の内容と重複する特典は、価値ではなく水増しである。

まず弱点を言語化する。「この講座だけでは○○が足りない」を書けなければ、特典は設計できない。

### 2. 価値の数値化が可能である

「便利です」ではなく、削減される時間・金額・工数で表せること。

- ✗ 「作業がラクになるテンプレート」
- ○ 「集計作業を毎回3時間削減するテンプレート（年6回で18時間）」

数値化できない特典は、受講生が価値を判断できない。

### 3. メイン価格の3倍の価値がある

特典の合計価値が、メイン商品価格の3倍を超えていること。
2番の数値化ができていれば計算できる。できないなら2番に戻る。

### 4. 永久提供

期間限定にしない。永久にアクセスできる形で提供する。
期限のある特典は購入を急がせる装置であり、受講生の利益ではない。

### 5. ロードマップに沿った段階的配置

すべてを最初に渡さない。学習マップ（工程2）のどの段階で必要になるかに合わせて配置する。

一度に全部渡すと、受講生は量に圧倒されて何も使わない。
「今これが必要」というタイミングで届くことが、それ自体で価値になる。

### 6. 本気の人向けの課題を用意する

上位層が物足りなさを感じないための、負荷の高い課題を含める。
全員が取り組む前提にはしない。**やりたい人だけが到達できる層**を作る。

これがないと、意欲の高い受講生から先に離脱する。
