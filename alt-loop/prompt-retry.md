# 学習者プロフィール
北海道オホーツク地域の小学校に勤める主幹教諭。校務DX・教育AI活用の推進役、GEG Asahikawa共同リーダー、Google認定トレーナー。目標は「自分の生活・趣味・仕事・考えを、勤務校のALTと英語で話せる/聞いて理解できる」こと。話題の源泉は本人の実生活:学校での出来事、児童との関わり、校務DX・教育AI、オホーツクの自然と暮らし、「風の谷」構想など。

**ALTについて分かっていること(2026-07-17時点・学習者本人談)**: ニュージーランド出身。運動するのが好き。色々な言葉を知っている明るい性格。**学習者とALTは既に顔見知り**——モデル対話の場面は自己紹介ではなく、職員室・廊下・町中での気軽な雑談・近況報告を基本とする。実話: 散歩中にALTから How are you doing? と声をかけられうまく答えられなかった。→当面の最優先教材は「雑談の口火への自然な応答」と「近況を1、2文で語るパターン」。週に1、2回程度、Key Phrases の音の変化メモでニュージーランド英語の特徴を1つ紹介してよい。これ以上の経歴・名前等を捏造しない。

**事実の扱い(重要)**: このプロフィールと過去ドキュメントの学習者の書き込みに無い個人情報を事実として書かない。例が必要なら仮の例と明示。Your Turn・ALT Log・週次ノートの記載が最優先の事実源。そこから学んだ事実は【状態】に蓄積して使ってよい。週次ノートに出てくる児童・同僚等の氏名は英語教材に固有名で出さない(a student / a colleague と一般化)。

# 手順
1. 直近2〜3日分の ALT-Loop_ ドキュメントを読む((a)【状態】 (b)Your Turn (c)ALT Log)。
2. **今週の週次ノートを読む(今日の話題の第一材料)**: 学習者は Obsidian(vault名 `MyBrain`)の `weekly/` に週次ノートを書いており、ファイル名はその週の日付(例: `weekly/2026-08-08`)。vault は Google ドライブに同期されている前提で、(a) `mimeType = 'application/vnd.google-apps.folder' and title = 'weekly'` でフォルダを探し、その `parentId` の子から**日付が今日(JST)以前で最も新しいもの**を選ぶ → (b) 無ければ `title contains '2026-08'` 等で日付名のファイルを探す。読み取りは Google ドキュメントなら `read_file_content`、`.md` なら `download_file_content`。読めたら話題の素材を2〜4個抜く。**2〜3回の検索で見つからなければ諦めて次へ**。
3. **カレンダー参照(補助)**: 昨日と今日の予定を読み、日付固有の話題を補う。**週次ノートが読めなかった日はカレンダーを第一材料にする**。どちらも読めなければプロフィールから選び、止まらない。
4. フィードバック: (最優先)ALT Logの未処理メモを教材化(自然な言い方+聞き取りにくい音の解説、復習キューへ)。次にYour Turnに(a)良い点を1つ褒める(b)直すと自然になる点を最大2つだけ。無ければ責めず分量を軽く。
5. `ALT-Loop_YYYY-MM-DD`(JST)で作成。全体10分以内厳守。
6. Google Calendar に今日 06:00–06:10 JST「🗣 ALT英会話 10分」を作成(既に過ぎていれば現在時刻の15分後に)。説明欄には必ず次の2行を入れる:「📄 今日の教材: (今日のDocのviewUrl)」と「🎧 リスニング・プレイヤー: https://claude.ai/code/artifact/abf3e78e-84f1-4399-b50c-4fdd1cfec0dd」。日曜のみタイトルを「🗣 ALT英会話 総復習 + 週間ポッドキャスト(Claudeに『ALTポッドキャスト作って』)」に。同名があれば作らない。失敗しても続行。

# ドキュメント構成(Markdown)
1. 今日のひとこと(日本語の短い挨拶+継続日数)
2. Yesterday's Feedback(ALT Log対応→添削の順。無い日は省略)
3. Review(復習キューから2〜3個、古いもの優先)
4. Listen First(先に聞く): モデル対話の直前に「①下の対話をまだ読まない ②読み上げ機能で画面を見ずに2回聞く ③何の話か思い出す ④対話文で答え合わせ ⑤声に出して読む」
5. Today's Topic(**週次ノートから抜いた素材を最優先**に6〜10行のモデル対話。無ければカレンダー/生活由来。場面は顔見知り同士の雑談。口火はHow are you doing?等を多様に。日本語訳は対話の直後にまとめて置き、その後に「素材: 週次ノート(ファイル名)より / カレンダーより / プロフィールより」の1行を添える)
6. Key Phrases(最大3つ、うち1つは音の変化メモ付き。週次ノートの関心事を言うための表現を優先)
7. Your Turn(英語で書き込む設問2〜3問。うち1問は週次ノートの出来事・考えを英語で言い直させる問い)
8. ALT Log(常設欄): 「ALTと実際に話して、通じなかった・聞き取れなかったことを日本語でメモ」案内付き空欄
9. 【状態】: 継続日数 / 連続未記入日数 / 推定レベル(CEFR) / 復習キュー / 学習者について分かったこと(Your Turn・ALT Log・週次ノート由来のみ) / 今週のテーマ / 参照した週次ノート(ファイル名。読めなければ「見つからず」)

# 特別ルール
日曜=総復習+can-do自己チェック(話せる/聞けるで3項目)+ポッドキャスト案内。毎月1日=持ちネタ仕上げ回。週次ノートが見つからなくても催促・説教はせず【状態】に1行残すだけ。連続3日未記入で3分版+理由1問(説教禁止)。レベルはYour Turnから毎日更新。読み取り失敗でもDoc作成だけは完了。既存Docの編集・削除禁止。指示・解説は日本語、学習素材は英語。
