# ALT英会話ループ — 話題の材料を Obsidian 週次ノートに変更

Claude の Routine（`ALT英会話ループ(毎朝5時)` と `ALT英会話ループ・リトライ(5:45)`）は
Web UI から作られているため、エージェント側から書き換えられない。
このフォルダの2ファイルが**貼り替え用の新しいプロンプト全文**。

| ファイル | 貼り替え先の Routine |
| --- | --- |
| `prompt-main.md` | ALT英会話ループ(毎朝5時) |
| `prompt-retry.md` | ALT英会話ループ・リトライ(5:45) |

## 先に必要な設定（1回だけ）

ループはクラウドで動くので、`obsidian://open?vault=MyBrain&file=weekly%2F2026-08-08`
のようなローカル URI は開けない。**vault の実体が Google ドライブから見える必要がある。**

いずれか1つ:

1. **推奨** — `MyBrain` vault（または `weekly` フォルダだけ）を Google ドライブ デスクトップの
   同期対象フォルダに置く。ファイル名の規則（`weekly/2026-08-08.md`）はそのままでよい。
2. `weekly` フォルダを Google ドライブ上に作り、週次ノートをそこにコピー/エクスポートする。

設定できているかの確認: Google ドライブの検索で `weekly` フォルダと、その中の
`2026-08-08` が出てくればループからも読める。

## 変更点（旧プロンプトとの差分）

- **手順3を新設** — 今週の週次ノートを Drive から探して読む。
  - `weekly` フォルダを探し、その中で**日付が今日(JST)以前で最も新しい**ノートを今週分とする。
  - Google ドキュメント形式なら `read_file_content`、`.md` なら `download_file_content`。
  - 出来事・関心事・予定・感情を 2〜4 個抜き出して today's topic の素材にする。
  - 2〜3回の検索で見つからなければ諦めて次へ（10分制限を守る）。
- **カレンダーは補助に降格** — 週次ノートが読めた日は日付固有の話題（出張・行事）の補完に使う。
  読めなかった日は従来どおりカレンダーが第一材料、それも駄目ならプロフィール。
- **Today's Topic** — 週次ノート由来の素材を最優先。日本語訳の後に
  「素材: 週次ノート 2026-08-08 より / カレンダーより / プロフィールより」の1行を出す（出どころが毎朝見える）。
- **Key Phrases / Your Turn** — 週次ノートの関心事を英語で言うための表現を優先。
  Your Turn の1問は週次ノートの出来事を英語で言い直させる問いにする。
- **【状態】に「参照した週次ノート」を追加** — ファイル名、読めなければ「見つからず」。
  同期設定が壊れたときに毎朝の Doc を見るだけで気づける。
- **事実の扱いに週次ノートを追加** — 週次ノートは Your Turn / ALT Log と同格の最優先の事実源。
  ただし児童・保護者・同僚の氏名は英語教材に固有名で出さず、a student / a colleague と一般化する。
- **週次ノートが無い日は催促しない** — 静かにフォールバックして【状態】に1行残すだけ。

## 追記: 週次ノート生成の Routine 化（2026-08-20）

週次ノート（`weekly/YYYY-MM-DD`、毎週土曜日付）は 2026-08-08 を最後に作られなくなっていた。
Claude アカウント上に該当 Routine は存在しない（＝ローカルの何かが作っていて止まった）ため、
クラウド Routine として復活させる。`prompt-weekly-note.md` がそのプロンプト全文。

**注意**: API 経由で作った Routine には Google Drive/Calendar コネクタが付かず動作しない
（検証済み・作成→削除済み）。**claude.ai の Routine 作成画面から**次の設定で作ること:

- 名前: 週次ノート生成(毎週土曜5:30)
- スケジュール: 毎週土曜 5:30 JST（UTC cron なら `30 20 * * 5`）
- 実行: 毎回新しいセッション
- コネクタ: Google Drive と Google Calendar を有効化
- プロンプト: `prompt-weekly-note.md` の全文

vault が Drive に同期されるまでは「weekly フォルダが見つからないので何もしない」で
静かに待機する設計なので、先に作っておいて問題ない。
