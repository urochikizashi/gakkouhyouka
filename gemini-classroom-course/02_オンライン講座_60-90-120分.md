# オンライン講座プログラム(60 分 / 90 分 / 120 分)

Meet または Zoom を想定。オホーツク管内は学校間の距離が長く冬季の移動も厳しいため、オンライン版は「集まらなくても受けられる」本命形式として設計します。対面版の焼き直しではなく、**事前に潰す・細かく区切る・チャットで見える化**の 3 原則で組み直しています。

内容の骨格は対面版と同じく初任段階の 2 大困り感(①よい授業をつくる ②学級経営の手立て)に直結させ、**「時間×質」の 2 軸フレーム**(時短=下書きを任せる/質=壁打ちで引き出しを増やす)を冒頭 1 分で提示します。ハンズオンのコース制(授業コース/学級経営コース)・質の壁打ちメニュー・頻出 Q&A 台本は対面版([01_対面講座](01_対面講座_60-90-120分.md))と共通です。

## オンライン特有の設計方針

- **二画面問題への対策**: 受講者は「会議画面」と「自分の Classroom」を行き来する。1 画面の人が多い前提で、①スマホで会議・PC で操作(推奨)、②画面半分ずつ、の 2 パターンを事前案内と冒頭の両方で説明
- 対面より**説明を短く・操作を細かく区切る**。「Gemini タブを開いたらチャットに『開けた』」方式で全員の位置を常に把握
- プロンプトは**口頭で読み上げず、チャットに貼る**(コピペで試せる)。進行補助がいれば貼り係を任せる
- 開始 10 分前から「接続・ログイン確認タイム」。**本編は環境が揃った状態で始める**
- 録画して後日配布(部活動・冬季対応で出られない人向け)。**冒頭に録画と配布範囲を告知し、発言・顔出しが録画に入ることの同意を取る**(顔出しなし・チャット参加のみでも OK と明言)
- 推奨定員: 講師 1 人+進行補助 1 人で 20 人まで。補助なしなら 12 人まで

## 共通の事前準備

- 事前案内メールに記載: 当日使う端末(Classroom にログインできるもの)、可能なら 2 画面(PC+スマホ)、来週の授業の単元を 1 つ、手持ちの課題プリントがあれば手元に
- **事前チェックフォーム**(Google フォーム): 「自分のクラスに Gemini タブが見えるか」を事前回収 → 見えない人には**管理者への依頼文面**を先に送る(当日のトラブルを前日までに潰す)。事前 3 問アンケート(負担感・使えそう感・助けてほしい仕事)も同じフォームで
- 講師側: デモの画面録画(通信障害時の保険)、サブ端末で自分の共有画面の見え方を監視、ブラウザズーム 150% 常用、可能なら進行補助 1 名(チャット拾い係)
- **事後フォロー**: 1 週間後に「使ってみましたか?」フォーム+質問受付。オンライン開催なら 15 分の「放課後相談会」を後日設定しやすい(対面より継続支援に向く)

## 60 分版「まず 1 つ、明日の授業で使う」

ゴール: 対面 60 分版と同じ(生成→検証→改善→保存の 1 サイクル)。ただし操作の区切りを細かく。

| 時間 | 内容 | 進め方 |
|---|---|---|
| −0:10–0:00 | 接続確認タイム | 早く入った人から音声・ログイン・Gemini タブ確認。画面には「確認 3 ステップ」を表示しておく |
| 0:00–0:05 | オープニング | 録画告知+チャットで「今週の授業準備時間」を数字で投稿。**時間×質の 2 軸を 1 枚で提示**し、ゴール「1 つ作って保存して退出する」 |
| 0:05–0:15 | デモ「10 分で明日の授業準備」 | 画面共有(ズーム 150%)でテスト生成→条件追加→Docs 書き出し。安全ルールはデモ内で実演。間違い例スクショも用意 |
| 0:15–0:20 | 最終セットアップ | 全員 Gemini タブを開き、チャットに「開けた」。開けない人は進行補助が個別対応(全体は止めない)。**開けなかった人には「今日は見る参加+録画で後日実践」と明るく案内** |
| 0:20–0:42 | ハンズオン: 2 コースから 1 つ作る | **授業コース**(小テスト/ワークシート)と**学級経営コース**(学級通信/朝の会ネタ)のプロンプト例を両方チャットに貼り、選ばせる → 手順を 4 区切りで指示: ①生成(5 分)→ ②3 箇所検証(5 分)→ ③条件を 1 つ足して再生成(5 分)→ ④Docs 書き出し(3 分)。区切りごとに「できた人は🔵」で進捗確認。できた物の一部をチャットに貼ってもらい進捗を見える化 |
| 0:42–0:50 | ブレイクアウト共有(2〜3 人・7 分) | 話す順番(名前順)と話題(①作った物 ②明日どう使う)を画面に表示してから送り出す |
| 0:50–1:00 | クロージング | 各部屋から一言をチャットで回収 → 良い例 2 つ紹介 → 今夜の 3 ステップ → 頻出 Q&A 3 つ → 事後 3 問フォーム(URL をチャットに) |

## 90 分版「授業準備+評価まで」

| 時間 | 内容 | 進め方 |
|---|---|---|
| −0:10–0:00 | 接続確認タイム | 同上 |
| 0:00–0:07 | オープニング | 録画告知+事前フォームの困り感集計を画面共有(「みんな同じ」と見せて安心させる) |
| 0:07–0:17 | デモ | 同上 |
| 0:17–0:22 | 最終セットアップ | 同上 |
| 0:22–0:44 | ハンズオン①: 2 コースから 1 つ作る | 60 分版と同じ 2 コース制・4 区切り方式。「怪しい箇所を見つけたらチャットへ」→ 拾って全体で検証の実演 |
| 0:44–1:00 | ハンズオン②: ルーブリック | 手持ち課題(ない人はハンズオン①の成果物)からルーブリック生成 → 自分の言葉に直す → 保存。**AI 提案フィードバックは講師画面のデモのみ**(環境依存のため。正直に言う) |
| 1:00–1:10 | ハンズオン③: 質の壁打ち(選択制) | A: 発問の壁打ち / B: 声かけの引き出し / C: 子ども役シミュレーション / D: 難易度別・複式学級の間接指導課題。「時短で浮いた時間をここに使う」と枠づけ、プロンプト集の番号をチャットに貼るだけで各自進める |
| 1:10–1:18 | 「明日の 1 コマ」設計 | 個人ワーク。**カメラオフ OK と明言**(作業に集中)。残り 2 分でチャットに 1 行宣言 |
| 1:18–1:26 | ブレイクアウト共有(3 人・8 分) | 成果物の画面共有の練習も兼ねる(共有ボタンの場所を先に見せる) |
| 1:26–1:30 | クロージング | 今夜の 3 ステップ、生徒利用の条件、録画・資料配布、事後フォーム |

## 120 分版「授業と学級経営、初任の一年を乗り切る使い方まで」

長丁場なので**前後半制+休憩**で集中を保ちます。

| 時間 | 内容 | 進め方 |
|---|---|---|
| −0:10–0:00 | 接続確認タイム | 同上 |
| 0:00–0:10 | オープニング | 録画告知+フォーム集計共有。オホーツクの文脈(移動距離・相談相手の少なさ)に触れ、「オンラインでつながる相談ネットワーク」の意義を語る |
| 0:10–0:20 | デモ | 同上 |
| 0:20–0:25 | 最終セットアップ | 同上 |
| 0:25–0:47 | ハンズオン①: 2 コースから 1 つ作る | 同上 |
| 0:47–1:02 | ハンズオン②: ルーブリック | 同上 |
| 1:02–1:12 | 休憩(10 分) | 「戻ったらチャットに🔵」で復帰確認。質問はチャットに書き溜めて OK と案内 |
| 1:12–1:27 | ハンズオン③: 質の壁打ち(選択制) | A/B/C/D(90 分版と同じ) |
| 1:27–1:42 | ハンズオン④: 学級経営・初任の一年 | 懇談会の想定問答・保護者電話の前整理(主任・管理職へ一報の鉄則をここで刷り込む)・未経験部活の練習メニュー・初任研レポートの構成から 1 つ。NotebookLM は紹介のみ |
| 1:42–1:54 | 「明日の 1 コマ+校内共有」設計 | 個人ワーク(カメラオフ OK)+チャット宣言(授業での使い所+職員室で誰に見せるか) |
| 1:54–2:08 | ブレイクアウト共有(3〜4 人・10 分)+全体共有 | 各部屋の代表 1 人が 1 分報告(部屋内で先に指名させる) |
| 2:08–2:20 | 生徒利用と安全 | ケース討議はチャット投票(「生徒の作文を入れていい? ○/×」)で全員参加型に → 頻出 Q&A 台本(対面版参照)で解説 |
| 2:20–2:30 | クロージング | 今夜の 3 ステップ、事後フォロー(1 週間後フォーム+オンライン相談会の日程)、事後フォーム |

## オンライン特有のつまずき対応表

| 症状 | 対応 |
|---|---|
| 会議に入れない/音声が出ない | 接続確認タイムで解決。以後は進行補助がチャットで個別対応 |
| 1 画面で会議と Classroom を行き来できない | スマホで会議・PC で操作に切替(冒頭の案内スライドを再掲) |
| Gemini タブが見えない | 事前フォームで前日までに潰す。当日発覚は「見る参加」+録画とプロンプト集で後日実践、と明るく案内 |
| 共有画面の文字が小さい | ズーム 150% 常用。「見えない」とチャットで言いやすい空気をつくる(冒頭で一度わざと聞く) |
| ブレイクアウトで無言になる | 話す順番(名前順)と話題を画面提示してから送り出す。3 人部屋にする(2 人だと欠けた時に 1 人になる) |
| 個人ワーク中に全員無反応で不安になる | 仕様と割り切る。BGM 的に「あと○分」だけアナウンス |
| 講師側の回線断 | 進行補助が場をつなぎ、デモ動画共有に切替。復帰手順(再入室・再開合図)を冒頭に案内 |
