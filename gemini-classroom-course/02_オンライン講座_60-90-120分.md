# オンライン講座プログラム(60 分 / 90 分 / 120 分)

Meet または Zoom を想定。オホーツク管内は学校間の距離が長く冬季の移動も厳しいため、オンライン版は「集まらなくても受けられる」本命形式として設計します。

## オンライン特有の設計方針

- **二画面問題への対策**: 受講者は「会議画面」と「自分の Classroom」を行き来する。1 画面しかない人が多い前提で、①スマホで会議・PC で操作、②画面半分ずつ、の 2 パターンを開始時に案内
- 対面より**説明を短く・操作を細かく区切る**(「Gemini タブを開いたらチャットに『開けた』と書いてください」方式で全員の位置を把握)
- プロンプトは**口頭で読み上げず、チャットに貼る**(コピペで試せる)
- 共有・交流はブレイクアウト+チャット。発言ハードルを下げるためチャット多用
- 開始 10 分前から「接続・ログイン確認タイム」を設ける(本編の時間を守るため)
- 録画して後日配布(冬季欠席・部活動対応で出られない人向け)

## 共通の事前準備

- 事前案内メールに記載: 当日使う端末(Classroom にログインできるもの)、可能なら 2 画面(PC+スマホ)、来週の授業の単元を 1 つ、事前チェック用リンク(自分のクラスに Gemini タブが見えるか)
- **事前チェックフォーム**(Google フォーム): 「Gemini タブが見えたか」を事前回収 → 見えない人には管理者依頼文面を先に送る(当日のトラブルを前日までに潰す)
- 講師側: デモの画面録画(通信障害時の保険)、サブ端末で自分の共有画面の見え方を監視、可能なら進行補助 1 名(チャット拾い係)

## 60 分版「まず 1 つ、明日の授業で使う」

| 時間 | 内容 | 進め方 |
|---|---|---|
| −0:10–0:00 | 接続確認タイム | 早く入った人から音声・ログイン・Gemini タブ確認。BGM 代わりに操作画面を流しておく |
| 0:00–0:05 | オープニング | チャットで「今週の授業準備時間」を数字で投稿してもらう。ゴール提示 |
| 0:05–0:15 | デモ「10 分で明日の授業準備」 | 画面共有でテスト生成→ルーブリック→誤解対応。**ズーム(拡大)を多用**、操作は実況中継style |
| 0:15–0:20 | セットアップ | 全員 Gemini タブを開き、チャットに「開けた」。開けない人は挙手ボタン → 進行補助が個別対応(全体は止めない) |
| 0:20–0:38 | ハンズオン①: テスト生成 | プロンプト例をチャットに貼る → 各自生成 → 「できた人は問題を 1 問チャットに貼ってください」で進捗可視化 |
| 0:38–0:48 | ハンズオン②: 選択制 | A: ルーブリック / B: 誤解対応 / C: 翻訳。チャットに各プロンプト例を貼る |
| 0:48–0:55 | 共有 | ブレイクアウト(2〜3 人・5 分)で「明日どう使う?」→ 戻ってチャットに一言 |
| 0:55–1:00 | クロージング | 安全ルール 3 つ、プロンプト集(ファイル送付)、録画配布の案内 |

## 90 分版「授業準備+評価まで」

|---|---|---|
| −0:10–0:00 | 接続確認タイム | 同上 |
| 0:00–0:07 | オープニング | チャット投稿+Google フォームで困り感 1 分アンケート(結果を画面共有、「みんな同じ」と見せる) |
| 0:07–0:17 | デモ | 同上 |
| 0:17–0:22 | セットアップ | 同上 |
| 0:22–0:40 | ハンズオン①: テスト生成 | 同上(検証: 「怪しい問題を見つけたらチャットへ」→ 拾って全体で確認) |
| 0:40–0:55 | ハンズオン②: ルーブリック+AI 提案フィードバック | ルーブリックは各自実施。フィードバック提案は講師画面のデモ中心(受講者環境に記述課題がない前提) |
| 0:55–1:05 | ハンズオン③: 選択制 | A: 誤解対応 / B: 導入ストーリー(地域素材) / C: 翻訳 |
| 1:05–1:15 | 「明日の 1 コマ」設計 | 個人ワーク。カメラオフ OK と明言(作業に集中させる)。残り 3 分でチャットに 1 行宣言 |

| 1:25–1:30 | クロージング | 安全ルール、生徒利用の条件、録画・資料配布、次の一歩 |

## 120 分版「授業準備から校務・校内展開まで」

長丁場なので**前後半制+休憩**で集中を保ちます。

| 時間 | 内容 | 進め方 |
|---|---|---|
| −0:10–0:00 | 接続確認タイム | 同上 |
| 0:00–0:10 | オープニング | フォームアンケート+結果共有。オホーツクの文脈(移動距離・相談相手の少なさ)に触れ、オンラインでつながる意義も語る |
| 0:10–0:20 | デモ | 同上 |
| 0:20–0:25 | セットアップ | 同上 |
| 0:25–0:45 | ハンズオン①: テスト生成 | 同上 |
| 0:45–1:00 | ハンズオン②: ルーブリック+AI 提案フィードバック | 同上 |
| 1:00–1:10 | 休憩(10 分) | 「戻ったらチャットに🔵」で復帰確認 |
| 1:10–1:25 | ハンズオン③: 選択制 | A: 誤解対応 / B: 導入ストーリー / C: 翻訳 |
| 1:25–1:40 | ハンズオン④: 校務への応用 | 保護者文書下書き・行事案内翻訳・画像作成。NotebookLM は紹介のみ |
| 1:40–1:55 | 「明日の 1 コマ+校内共有」設計 | 個人ワーク(カメラオフ OK)+チャット宣言 |
| 1:55–2:10 | ブレイクアウト共有(3〜4 人・10 分)+全体共有 | 各部屋の代表 1 人が 1 分報告(事前に部屋内で指名) |
| 2:10–2:20 | 生徒利用と安全 | ケース討議はチャット投票(「入れていい? ○/×」)で全員参加型に |
| 2:20–2:30 | クロージング | 資料・録画配布、事後フォロー(チャットグループ・次回オンライン相談会)の案内、アンケート |

## オンライン特有のつまずき対応表

| 症状 | 対応 |
|---|---|
| 会議に入れない/音声が出ない | 接続確認タイムで解決。以後は進行補助がチャットで個別対応 |
| 1 画面で会議と Classroom を行き来できない | スマホで会議・PC で操作に切替を案内(冒頭で全体に説明済み) |
| Gemini タブが見えない | 事前フォームで潰しておく。当日発覚した人は「見る参加」+録画とプロンプト集で後日実践 |
| 講師の共有画面の文字が小さい | ブラウザズーム 150% 常用。チャットで「見えない」と言いやすい空気をつくる |
| ブレイクアウトで無言になる | 部屋ごとに話す順番(名前順)と話題(①作った物 ②明日どう使う)を事前提示 |
| 講師側の回線断 | 進行補助が場をつなぐ。デモ動画を共有して視聴に切替。復帰できない場合の再開手順を冒頭に案内 |
