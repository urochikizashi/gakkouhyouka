# Gemini in Classroom 講座セット(オホーツク若手教員向け)

「明日の授業から使えそう」と感じてもらい、日々の困り感(授業準備・評価・文書作成の負担)を減らすことをゴールにした研修パッケージです。

## 対象と前提

- **対象**: オホーツク管内(北見・網走・紋別ほか)の若手教員。小規模校・へき地校勤務、校内に ICT に詳しい人が少ない環境を想定。
- **前提環境**: 自治体の Google Workspace for Education(Fundamentals / Standard / Plus)。Gemini in Classroom は追加費用なしで利用可能。
- **日本語対応**: Gemini in Classroom は 2026 年 5 月に日本語提供が開始済み。音声レッスン(ポッドキャスト風)など一部機能は英語のみ。

## 利用条件の重要な注意(講座でも必ず伝える)

- 教員は Education Fundamentals / Standard / Plus で利用可。
- 生徒・学生の利用には年齢・校種・管理者設定の条件がある(日本では当初、高等教育の 18 歳以上。2026 年 8 月に全年齢への拡大が発表されたが、**管理コンソールでの有効化と自治体・教育委員会のガイドライン確認が必須**)。
- 児童生徒の氏名・成績などの個人情報をプロンプトに入れない。生成物は必ず教員が検証してから使う。
