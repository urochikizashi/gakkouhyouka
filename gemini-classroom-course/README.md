# Gemini in Classroom 講座セット(オホーツク若手教員向け)

「明日の授業から使えそう」と感じてもらい、日々の困り感を減らすことをゴールにした研修パッケージです。**初任段階の 2 大困り感 — ①よい授業をつくる ②学級経営の手立て — に直結させ**、すべての内容を「時間×質」の 2 軸で設計しています:

- **時間の軸(時短)**: 下書き・変換・翻訳を任せて仕上げだけ自分でやる(小テスト・学級通信・保護者文書)
- **質の軸(腕を上げる)**: 壁打ち相手にして引き出しを増やす(発問を磨く・子ども役に授業を試す・声かけの選択肢・トラブル対応の前整理)

時短だけの研修は「AI に書かせた物」で終わります。質の使い方を混ぜることで、使うほど授業と学級経営がうまくなる構造にしています。あわせて初任ならではの場面(研究授業・初任研レポート・未経験部活の顧問・保護者電話)も第 3 の柱としてカバーします。

この 2 軸・2 テーマ構成は研究知見に接地させています: 初任教師の最大の困難は「授業」と「多忙」で 1 年では克服しきれず、困難を下げるのは「相談しやすい環境」と「自分から援助を求める力」(真田・蘭 2024)。知見の全体と更新の仕組みは [05_初任段階レンズ.md](05_初任段階レンズ.md) にまとめており、**新しい研究・実施データが入るたびにレンズ → 講座ファイルの順で更新します**。

## 講座の選び方(目安)

| 枠 | 向いている場面 |
|---|---|
| 60 分 | 放課後の校内ミニ研修。「1 つ作って保存して帰る」に全振り |
| 90 分 | 校内研修の 1 コマ。授業準備+評価(ルーブリック)まで |
| 120 分 | 管内研究会・長期休業中の研修。校務活用+校内で広める側の育成まで |
| 対面 | 同一校・近隣校で集まれる場合。机間巡視で個別に助けられるのが強み |
| オンライン | 管内の広域参加・冬季。事前チェックで環境問題を前日までに潰せるのが強み。録画配布で欠席者もカバー |

どの版も共通で「事前・事後の同じ 3 問アンケート」で困り感の変化を測り、「1 週間後フォローフォーム」で伴走します(詳細は各講座ファイル)。

## 対象と前提

- **対象**: オホーツク管内(北見・網走・紋別ほか)の若手教員。小規模校・へき地校勤務、校内に ICT に詳しい人が少ない環境を想定。
- **前提環境**: 自治体の Google Workspace for Education(Fundamentals / Standard / Plus)。Gemini in Classroom は追加費用なしで利用可能。
- **日本語対応**: Gemini in Classroom は 2026 年 5 月に日本語提供が開始済み。音声レッスン(ポッドキャスト風)など一部機能は英語のみ。

## 利用条件の重要な注意(講座でも必ず伝える)

- 教員は Education Fundamentals / Standard / Plus で利用可。
- 生徒・学生の利用には年齢・校種・管理者設定の条件がある(日本では当初、高等教育の 18 歳以上。2026 年 8 月に全年齢への拡大が発表されたが、**管理コンソールでの有効化と自治体・教育委員会のガイドライン確認が必須**)。
- 児童生徒の氏名・成績などの個人情報をプロンプトに入れない。生成物は必ず教員が検証してから使う。
