# 対面講座プログラム(60 分 / 90 分 / 120 分)

## 共通の設計方針

- **8 割ハンズオン**。説明は最小限にして「自分の来週の授業のもの」を作って帰ってもらう
- 成果物ファースト: 全員が最低 1 つ、**明日の授業で使える現物**(小テスト・ルーブリック・導入ネタ等)を持ち帰る
- 例はすべてオホーツク文脈(流氷・ホタテ・酪農・カーリング・知床・小規模校)にして「自分の学校の話だ」と感じてもらう
- 若手の困り感(授業準備時間・教材づくり・評価・保護者文書)から入る。AI の話から入らない

## 共通の事前準備

- 受講者への事前案内: **自分のアカウントで Classroom にログインできる端末を持参**(校務用 Chromebook 推奨)、来週の授業の単元を 1 つ決めてくる
- 会場: Wi-Fi 実測、プロジェクタ、受講者用に予備端末 2〜3 台
- 配布物: [03_配布用プロンプト集.md](03_配布用プロンプト集.md) を印刷、安全ルールカード(A5・裏面に自治体ガイドライン要点)
- 講師: スクショ入りスライド(通信障害時の保険)、テストクラス作成済み
- **受付時チェック**: 入室時に「Gemini タブが見えるか」だけ先に確認 → 見えない人は予備端末 or ペア作業に回す(開始後のトラブル対応で全体を止めない)

## 60 分版「まず 1 つ、明日の授業で使う」

ゴール: 全員がテスト生成を体験し、明日使える小テストかワークシートを 1 つ持ち帰る。

| 時間 | 内容 | 進め方 |
|---|---|---|
| 0:00–0:05 | オープニング「今週、授業準備に何時間かけましたか?」 | 挙手アンケート。困り感を口に出してもらう。講座ゴール提示 |
| 0:05–0:15 | デモ「10 分で明日の授業準備」 | 講師がライブで: テスト生成(中1理科・光)→ ルーブリック → よくある誤解。**間違いが出たら「だから検証が必要」とその場で教材化** |
| 0:15–0:20 | セットアップ | 全員 Gemini タブを開く。詰まった人はペアに合流 |
| 0:20–0:40 | ハンズオン①: テスト生成 | 自分の来週の単元で 10 問生成 → 3 問だけ検証 → 条件(学年・難易度・形式)を足して再生成。机間巡視で個別支援 |
| 0:40–0:50 | ハンズオン②: 選択制 | A: ルーブリック作成 / B: よくある誤解 / C: 翻訳(お便り) から 1 つ |
| 0:50–0:57 | ペア共有「明日どう使う?」 | 作った物を見せ合い、使う場面を宣言し合う |
| 0:57–1:00 | クロージング | 安全ルール 3 つ(個人情報 NG・検証必須・ガイドライン確認)、プロンプト集配布、次の一歩 |

## 90 分版「授業準備+評価まで」

ゴール: 60 分版の内容+ルーブリックと AI 提案フィードバックまで体験し、「評価の時短」を実感して帰る。

| 時間 | 内容 | 進め方 |
|---|---|---|
| 0:00–0:07 | オープニング+困り感の付箋出し | 付箋で「一番時間を取られている仕事」を出し合い、板書で分類(準備/評価/文書/その他) |
| 0:07–0:17 | デモ「10 分で明日の授業準備」 | 60 分版と同じ |
| 0:17–0:22 | セットアップ | 同上 |
| 0:22–0:42 | ハンズオン①: テスト生成 | 60 分版と同じ(検証込み) |
| 0:42–0:57 | ハンズオン②: ルーブリック+AI 提案フィードバック | 手持ち課題からルーブリック生成 → 講師のテストクラスでフィードバック提案のデモ体験 |
| 0:57–1:07 | ハンズオン③: 選択制 | A: 誤解対応 / B: 導入ストーリー(流氷・ホタテ等の地域素材) / C: 翻訳 |
| 1:07–1:17 | 「明日の 1 コマ」設計 | 個人ワーク: 作った物を来週の授業のどこで使うか、略案メモに落とす |
| 1:17–1:25 | グループ共有(3〜4 人) | 成果物と使い方を共有。良い使い方を全体に 2 つ拾う |
| 1:25–1:30 | クロージング | 安全ルール、生徒利用の条件(年齢・管理者設定・教委ガイドライン)、プロンプト集、校内での広め方 |

## 120 分版「授業準備から校務・同僚への広げ方まで」

ゴール: 90 分版の内容+校務活用(文書・NotebookLM 紹介)と「校内で自分が広める側になる」設計まで。

| 時間 | 内容 | 進め方 |
|---|---|---|
| 0:00–0:10 | オープニング+困り感の付箋出し | 90 分版と同じ+「オホーツクならでは」の困り感(ICT 支援員が遠い、相談相手が少ない)にも触れる |
| 0:10–0:20 | デモ「10 分で明日の授業準備」 | 同上 |
| 0:20–0:25 | セットアップ | 同上 |
| 0:25–0:45 | ハンズオン①: テスト生成 | 同上 |
| 0:45–1:00 | ハンズオン②: ルーブリック+AI 提案フィードバック | 同上 |
| 1:00–1:15 | ハンズオン③: 選択制 | 同上(A/B/C) |
| 1:15–1:25 | 休憩 | |
| 1:25–1:40 | ハンズオン④: 校務への応用 | 保護者向け文書の下書き・行事案内の翻訳・スタータープロンプトでの画像作成。NotebookLM は紹介デモのみ(深追いしない) |
| 1:40–1:55 | 「明日の 1 コマ+校内共有」設計 | 個人ワーク: 略案メモ+「職員室で誰に何を見せるか」を 1 行で決める |
| 1:55–2:10 | グループ共有+全体共有 | グループ(3〜4 人)→ 各グループ 1 分で全体発表 |
| 2:10–2:20 | 生徒利用と安全の話 | 年齢・エディション条件、個人情報、生成物の検証責任、教委ガイドライン。ケースで考える(「生徒の作文を入れていい?」) |
| 2:20–2:30 | クロージング | プロンプト集、事後フォロー(チャットグループ等)の案内、アンケート |

## つまずき対応表(机間巡視用)

| 症状 | 原因 | その場の対応 |
|---|---|---|
| Gemini タブがない | 管理者が未有効化/エディション | ペアに合流。後日管理者への依頼文面を渡す |
| ログインできない | 私物端末・別アカウント | 予備端末を貸す |
| 生成が英語で出る | プロンプトが英語混じり | 「日本語で」と明示させる |
| 生成内容が的外れ | 条件不足 | 学年・教科・単元・形式を足させる(これ自体が学び) |
| 進みが速すぎる人 | — | 選択制ハンズオンの別メニュー、または隣の人のサポート役を頼む |
| 会場ネット断 | — | スクショスライドで進行、ハンズオンは配布プロンプト集の「紙上演習」に切替 |
