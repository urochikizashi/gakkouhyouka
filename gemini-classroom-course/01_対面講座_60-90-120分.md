# 対面講座プログラム(60 分 / 90 分 / 120 分)

## 共通の設計方針

- **8 割ハンズオン**。説明は最小限にして「自分の来週の授業のもの」を作って帰ってもらう
- 成果物ファースト: 全員が最低 1 つ、**明日の授業で使える現物**(小テスト・ワークシート・導入ネタ・ルーブリック等)を、**保存(Docs 書き出し/コピー)まで済ませて**持ち帰る
- 例はオホーツク文脈(流氷・ホタテ・酪農・カーリング・知床・小規模校)を使うが、押し付けず「差し替え可」を毎回言う
- 若手の困り感(授業準備時間・教材づくり・評価・保護者文書)から入る。AI の話から入らない
- **推奨定員: 講師 1 人につき 12〜16 人**。それ以上は進行補助を 1 人つけるか、「隣同士助け合い」ルール+早く終わった人をサポーター任命で回す

## 共通の事前準備

- 受講者への事前案内: **自分のアカウントで Classroom にログインできる端末を持参**(校務用 Chromebook 推奨)、来週の授業の単元を 1 つ決めてくる、可能なら手持ちの課題プリント(紙 or ファイル)を 1 枚
- 会場: Wi-Fi 実測(全員同時生成に耐えるか)、プロジェクタ、受講者用に予備端末 2〜3 台
- 配布物: [03_配布用プロンプト集.md](03_配布用プロンプト集.md) を印刷、安全ルールカード(A5・裏面に自治体ガイドライン要点)
- 講師: スクショ入りスライド(通信障害時の保険)、テストクラス作成済み、**「間違い生成例」のスクショ**(デモで都合よく間違いが出なかった時に使う)
- **開始前セットアップ(受付〜開始)**: 入室した人から順に「ログイン → 自分のクラス → Gemini タブが見えるか」まで済ませてもらう。見えない人は予備端末 or ペア作業に割り振る。**本編開始時に全員の環境が揃っている状態を作るのが 60 分版成立の生命線**
- **荒天対応(冬季)**: 前日 15 時までに実施判断。中止ではなくオンライン版(同時間・短縮 60 分)に切り替える基準と接続先を事前案内に書いておく
- **事後フォロー(全時間版共通)**: 1 週間後に「使ってみましたか?」フォーム(使った/使ってない理由/質問欄)を送る。困り感低減は講座後の伴走で決まる

## 効果測定(全時間版共通)

事前(受付時)と事後(クロージング)で同じ 3 問を聞き、変化を見る。回収は紙または QR コードのフォームで(受付机に両方置くのが確実):

1. 授業準備・校務の負担感(5 段階)
2. 「明日の授業で AI を使えそう」という見込み(5 段階)
3. 一番助けてほしい仕事(自由記述)

## 60 分版「まず 1 つ、明日の授業で使う」

ゴール: 全員が生成→検証→改善→**保存**の 1 サイクルを回し、明日使える現物を 1 つ持ち帰る。欲張らない。

| 時間 | 内容 | 進め方 |
|---|---|---|
| 受付〜0:00 | 開始前セットアップ | ログイン+Gemini タブ確認+事前 3 問アンケート |
| 0:00–0:05 | オープニング「今週、授業準備に何時間かけましたか?」 | 挙手アンケート。困り感を口に出してもらう。ゴール提示「今日は 1 つ作って保存して帰る」 |
| 0:05–0:15 | デモ「10 分で明日の授業準備」 | ライブで: テスト生成(中1理科・光)→ 条件を足して改善 → Docs へ書き出し。**安全ルール(個人情報 NG・検証必須)はデモの中で実演しながら伝える**。間違いが出たら「だから検証」とその場で教材化、出なければ用意したスクショで同じ話をする |
| 0:15–0:20 | 最終セットアップ | 開始前に済まなかった人の救済。済んでいる人はプロンプト集の A を眺めて使うプロンプトを選ぶ |
| 0:20–0:45 | ハンズオン: 自分の単元で 1 つ作る | 基本はテスト生成。実技系教科(体育・音楽・美術等)は**ワークシートか導入ネタでも可**と明示。手順を板書: ①生成 → ②3 問(3 箇所)検証 → ③条件を 1 つ足して再生成 → ④**Docs に書き出して保存**。早く終わった人は第 2 メニュー(ルーブリック/誤解対応)へ、または隣のサポーター役 |
| 0:45–0:53 | ペア共有「明日どう使う?」 | 作った物を見せ合い、使う場面を宣言し合う。講師は良い例を 2 つ拾う |
| 0:53–1:00 | クロージング | 全体で良い例 2 つ紹介 → 「今夜の 3 ステップ」(プロンプト集末尾)→ 頻出 Q&A 3 つを先回りで回答 → 事後 3 問アンケート |

## 90 分版「授業準備+評価まで」

ゴール: 60 分版の 1 サイクル+**自分の課題からルーブリックを作る**体験。評価の時短を実感して帰る。

| 時間 | 内容 | 進め方 |
|---|---|---|
| 受付〜0:00 | 開始前セットアップ | 同上 |
| 0:00–0:07 | オープニング+困り感の付箋出し | 付箋で「一番時間を取られている仕事」→ 板書で分類(準備/評価/文書/その他)。「今日は準備と評価をやる」と宣言 |
| 0:07–0:17 | デモ「10 分で明日の授業準備」 | 60 分版と同じ(保存まで見せる) |
| 0:17–0:22 | 最終セットアップ | 同上 |
| 0:22–0:45 | ハンズオン①: 自分の単元で 1 つ作る | 60 分版と同じ(検証・保存込み) |
| 0:45–1:00 | ハンズオン②: ルーブリック | 持参した課題プリント(ない人はハンズオン①の成果物)からルーブリック生成 → 観点・段階を自分の言葉に直す → 保存。**AI 提案フィードバックは講師デモのみ**(利用可否が環境・提供状況に依存するため。「皆さんの環境で使えるかは管理者設定次第」と正直に言う) |
| 1:00–1:12 | ハンズオン③: 選択制 | A: よくある誤解 / B: 導入ストーリー(地域素材) / C: 翻訳(お便り) / D: **難易度別プリント・複式学級の間接指導課題**。プロンプト集の該当番号を示すだけで各自進める |
| 1:12–1:20 | 「明日の 1 コマ」設計 | 個人ワーク: 作った物を来週のどの時間のどの場面で使うか、配布の略案メモに 3 行で書く |
| 1:20–1:27 | グループ共有(3〜4 人) | 成果物と使い方を共有。良い使い方を全体に 2 つ拾う |
| 1:27–1:30 | クロージング | 今夜の 3 ステップ、頻出 Q&A、事後アンケート |

| 0:20–0:25 | 最終セットアップ | 同上 |
| 0:25–0:48 | ハンズオン①: 自分の単元で 1 つ作る | 同上 |

## 頻出 Q&A 台本(クロージング・質疑用)

- **Q: 生徒にも使わせられますか?**
  A: 教員利用と生徒利用は条件が別。日本では当初、高等教育の 18 歳以上のみでした。全年齢への拡大が発表されていますが、**管理コンソールでの有効化と自治体ガイドラインの確認が前提**です。今日の内容はすべて「教員が使う」範囲なので、明日から使えます。
- **Q: 無料ですか?**
  A: Education Fundamentals / Standard / Plus で追加費用なしで使えます(一部機能はエディション・提供状況で差があります)。
- **Q: 個人情報はどこまで入れていい?**
  A: 児童生徒の氏名・成績・作文などは入れない。単元名・学年・「うちのクラスの傾向」レベルの抽象度で十分機能します。
- **Q: 生成物が間違っていたら?**
  A: 間違えます(デモで見せた通り)。検証してから使うのは教材屋としての私たちの仕事。「下書き 8 割を AI、仕上げ 2 割を自分」が基本形です。
- **Q: Gemini タブが出ません**
  A: 管理者側の設定の可能性が高い。配布資料の「管理者への依頼文面」をそのまま送ってください。

## つまずき対応表(机間巡視用)

| 症状 | 原因 | その場の対応 |
|---|---|---|
| Gemini タブがない | 管理者が未有効化/エディション | ペアに合流。管理者への依頼文面(配布資料に同梱)を渡す |
| ログインできない | 私物端末・別アカウント | 予備端末を貸す |
| 生成が的外れ | 条件不足 | 学年・教科・単元・形式・分量の 5 点を足させる(これ自体が学び) |
| 保存の仕方がわからない | 初回操作 | 書き出し/コピー手順を板書に残しておき、そこを指す |
| 進みが速すぎる人 | — | 第 2 メニューへ、またはサポーター任命(「教えると定着する」と一言添える) |
| 会場ネット断 | — | スクショスライドで進行、ハンズオンは配布プロンプト集の「紙上演習」(プロンプトを紙に書いて練る)に切替 |
