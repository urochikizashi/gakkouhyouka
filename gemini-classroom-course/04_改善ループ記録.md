# 改善ループ記録(2 周)

このセットは「v1 ドラフト → 批評 → 改訂(ループ 1)→ 再批評 → 改訂(ループ 2)」の手順で作成しました。何をなぜ変えたかの記録です。講座を実施したら、このファイルに「ループ 3(実施後の振り返り)」を追記していくことを推奨します。

## ループ 1: 「本当にその時間で回るか・本当に持ち帰れるか」

v1 に対する批評レンズ: 時間配分の現実性/初心者のつまずき先回り/「明日使える」への直結度/機能理解の正確さ/講師も初心者という前提。

| # | 指摘 | 対応 |
|---|---|---|
| 1 | 60 分版でセットアップ 5 分+選択制ハンズオン 10 分は初心者集団では破綻する(3 メニュー説明だけで数分溶ける) | 60 分版は「1 サイクル(生成→検証→改善→保存)を 1 本だけ」に全振り。選択制は「早く終わった人の第 2 メニュー」に格下げ。セットアップは受付時に前倒しし「開始前に環境が揃っている」を成立条件として明記 |
| 2 | 「AI 提案フィードバックを体験」と書いたが、提供状況・管理者設定に依存し受講者環境で使えない可能性が高い | 全版で「講師デモのみ。皆さんの環境で使えるかは管理者設定次第、と正直に言う」に修正 |
| 3 | 生成して満足して終わり、保存方法が講座に入っていない → 持ち帰れない | ハンズオン手順の最終ステップに「Docs へ書き出して保存」を組み込み。講師チェックリストにも保存方法の事前確認を追加(「受講者が一人で最初に詰まるのはここ」) |
| 4 | 講師 1 人で何人まで見られるかが未定義 | 推奨定員(対面 12〜16 人、オンライン補助ありで 20 人)と、超過時のサポーター任命ルールを明記 |
| 5 | 講座後、職員室で一人になった瞬間に手が止まる問題への手当てがない | プロンプト集末尾に「今夜やること 3 ステップ(15 分)」を追加。1 週間後フォローフォーム+質問受付を全版共通設計に |
| 6 | 「Gemini タブが出ない」受講者への出口が「後日問い合わせて」で終わっていた | そのまま送れる「管理者への依頼文面」をプロンプト集に同梱。オンライン版は事前チェックフォームで前日までに検出して文面を先送り |
| 7 | 複式学級・少人数校の文脈がプロンプト集にしかなく、講座本体に出てこない | 90/120 分版の選択制に「D: 難易度別・複式学級の間接指導課題」を追加 |
| 8 | 冬のオホーツクで対面講座が飛ぶリスクに触れていない | 対面版に「前日 15 時判断でオンライン 60 分版に切替」の荒天対応を追加 |
| 9 | 実技系教科(体育・音楽・美術)の受講者にテスト生成は刺さらない | 「ワークシートか導入ネタでも可」を全ハンズオンに明記 |
| 10 | デモ中に都合よく AI が間違えなかったら「検証が必要」の実演ができない | 講師チェックリスト Phase 2 で「間違い生成例のスクショを事前に確保」→ デモ台本に「出なければスクショで同じ話をする」を明記 |
| 11 | 講師の練習時間見積もり(Phase 1: 2〜3 時間)が楽観的 | 4〜5 時間に修正し「1 日 1 時間×1 週間」のペース提案を追加。デモ用サンプル課題ファイルの準備、失敗談の用意も追加 |
| 12 | 録画配布(オンライン)の肖像・発言の扱いが未整理 | 冒頭での録画告知・配布範囲の同意・顔出しなし参加 OK を明記 |
| 13 | 翻訳機能を保護者文書にそのまま使うと誤訳リスク | プロンプト集と 120 分版に「重要文書は必ず確認者を通す」を追加 |

## ループ 2: 「ファイル間の整合・受講者体験の通し・選び方」

改訂版に対する批評レンズ: ファイル間の不整合/講座前後の体験の切れ目/主催者目線(どの枠を選ぶか)。

| # | 指摘 | 対応 |
|---|---|---|
| 1 | 講師チェックリスト Phase 3 のデモ台本(テスト→ルーブリック→誤解対応)が、改訂後のデモ(テスト→条件追加→保存)と食い違っていた | チェックリスト側を修正して一致させた |
| 2 | 対面版の事前・事後アンケートの回収方法が未指定(初任者は「アンケートやります」だけでは動けない) | 「紙または QR フォーム、受付机に両方」を明記 |
| 3 | README に「60/90/120・対面/オンラインをどう選ぶか」の指針がなく、主催者(教頭・研修担当)が使いにくい | README に「講座の選び方」表を追加 |
| 4 | 効果測定(同じ 3 問の事前事後比較)と事後フォローが講座ファイルにしかなく、セット全体の設計として見えない | README の選び方セクションに共通設計として明記 |
